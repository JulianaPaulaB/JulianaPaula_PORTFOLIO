### 05 | Bank Marketing
**Term Deposit Subscription Prediction**

*Business Analytics · Classification · Predictive Modeling*

[View Project Repository](https://github.com/JulianaPaulaB/Classification-Project-Bank-Term-Deposit-Subscription-Prediction)

A classification project that uses customer information to predict whether a client is likely to subscribe to a bank term deposit. It explores how predictive modeling can support marketing campaign planning and customer prioritization.

**Project Work**
- Examined 41,188 records and 21 attributes from the UCI dataset.
- Removed 12 duplicate records.
- Excluded call duration to prevent data leakage because it is only known after a call ends.
- Prepared the dataset through imputation, standardization, and one-hot encoding.
- Compared Logistic Regression, K-Nearest Neighbors, Decision Tree, and Random Forest.
- Selected the model based on F1-score for the subscriber class.

**Model Evaluation: Logistic Regression**

| Metric | Result |
|---|---:|
| Accuracy | 83.03% |
| Precision (Yes) | 35.91% |
| Recall (Yes) | 64.55% |
| F1-score (Yes) | 46.15% |

The model identified approximately 65% of actual subscribers. However, its precision also shows that predictions would need further qualification before being used for campaign decisions.

**Tools:** Python · Pandas · Scikit-learn · Matplotlib · Jupyter Notebook · Joblib

### 06 | CarDekho
**Used Car Price Prediction**

*Predictive Analytics · Regression Modeling · Machine Learning*

[View Project Repository](https://github.com/JulianaPaulaB/Cardekho-Used-Car-Dataset/tree/main)

A regression project that estimates used car selling prices based on vehicle characteristics such as age, mileage, engine capacity, fuel type, and transmission.

**Project Work**
- Cleaned the dataset and removed duplicate records.
- Converted mileage, engine capacity, and maximum power into numerical values.
- Prepared a data preprocessing pipeline.
- Compared LASSO, Ridge, Elastic Net, Decision Tree, and Random Forest.
- Selected Random Forest based on its lowest RMSE.
- Saved and reloaded the model using Joblib.

**Model Evaluation: Random Forest**

| Metric | Result |
|---|---:|
| R² | 0.9194 |
| MAE | 74,693.13 |
| RMSE | 133,543.17 |

The model explained approximately 91.9% of the variation in selling prices within the test dataset.

**Tools:** Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn · Jupyter Notebook · Joblib

## 💭 How I Approach a Problem

I believe a good solution starts with understanding what actually needs to be addressed.

My usual approach is to:

1. **Understand the problem** – Identify the needs, users, and expected outcome.
2. **Organize the requirements** – Translate ideas into clear features, workflows, or analytical objectives.
3. **Plan before developing** – Establish how the system or analysis should work.
4. **Work with the information** – Prepare data and choose methods that suit the problem.
5. **Present the results** – Make findings and technical information clear and useful.

I continue to improve my technical skills through academic projects, hands-on practice, and independent learning.
